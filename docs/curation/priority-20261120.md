## 怎麼挑的

1. **共用素材**：pickfit 現有的 1,220 筆紀錄（slug、名稱、repo、類別、摘要），加上 harvest 的 36,111 個 lead 和其中 133 個查過 GitHub、還沒收錄的高星候選。
2. **九位策展 agent 並行**，每類一位，照同一份準則：
   - 先畫細分場景地圖，標出 pickfit 空白或薄弱的場景。
   - 每個場景只選一個冠軍；只有架構或體驗差很多時（CLI 與 GUI、自架與桌面）才多選一個。
   - 冠軍要知名、近期有維護、功能最完整、開源或免費、本地或可自架，而且能在沙盒裡驗。
   - 每款都要寫一句具體的「為什麼選它、不選同類的 X 和 Y」，並標出需要哪種沙盒。
3. **真實性核驗**：每個 GitHub repo 由策展 agent 和彙整時各用 `gh api` 查一次。repo 要存在、沒有 archived、近 12 個月有 push，星數和最後 push 日期都取 API 的值。改過名的 repo 用新名字（例如 `containers/podman` 現在是 `podman-container-tools/podman`）。
4. **去重**：
   - 和現有 1,220 筆比對：GitHub 軟體比 repo，沒有 repo 的比名稱。
   - 跨類別比對：同一款出現在兩類時，照 pickfit 自己的類別順序留在前面那類。
   - 結果只拿掉一筆：Immich 同時出現在 `media_files` 和 `other`，留在 `media_files`。
   - Prometheus 名稱撞到現有的 `prometheus`，但那筆是 `OAraLabs/Prometheus`（AI agent daemon），不是監控系統，所以保留。

這次沒有改 `data/software/`，沒有跑任何付費的管線指令，也沒有推送。

## 送進管線前要知道的事

- **薄弱類別有一部分是分類問題**：策展 agent 發現不少知名工具已經在目錄裡，只是被分到 `other` 或 `dev_cli`。
  - `media_files`：HandBrake、Stirling-PDF、LocalSend、Audacity、Transmission 在 `other`。
  - `data_db`：jq、yq、Miller、VisiData、Nushell、Harlequin 在 `dev_cli`。
  - `infra_devops`：k9s、dive、btop、bottom 在 `dev_cli`；rclone、Syncthing 在 `media_files`。

  照類別順序重新分類，這幾類不用新增就會變多。這要另外決定，這次沒動。
- **FFmpeg** 在 harvest 是 `skipped`：它的 GitHub repo 只是 git.ffmpeg.org 的鏡像，pickfit 的規則 11/19 初篩時就退了。要收的話得手動送，或調整規則。
- **沙盒驗起來比較難的**：
  - 要 Docker 或 root：kind、Coolify。
  - 要叢集或 git 主機：Headlamp、Woodpecker CI。
  - 要 KVM 跑 Android 模擬器：Mobile MCP。
  - 要 Ghidra 的 GUI：GhidraMCP。
  - 要 Postgres 和 Redis（`linux+services`）：Immich。
  - 只能做 TCP connect 掃描：Nmap。
  - 要免費的 Figma token：Framelink Figma MCP。
  - 要 GPU：vLLM、Upscayl。

  沙盒需求寫在每一列，大多落在已經打通的 `linux`、`linux+gpu`、`linux+services`、`linux+display`。
- **授權要再確認**：
  - Open WebUI 是加了品牌條款的 BSD-3 變體，要確認合不合 pickfit 的開源規則。
  - Nmap 是 NPSL，可以免費用，但不是標準 OSI 授權。
  - 下面幾個 GitHub 顯示 NOASSERTION，表上寫的是策展 agent 依專案說明填的：FFmpeg、ImageMagick、Czkawka、Zotero、Neovim、Meilisearch、Metabase、DB Browser for SQLite、Adminer。
- **核驗比較弱的**：Thunderbird 用官網網址（HTTP 302），沒有 GitHub 星數可查。BookStack 的開發已經移到 Codeberg，但 GitHub 鏡像仍持續更新。
- 「為何是同類最佳」那一欄是策展 agent 寫的英文原句，表格裡照原文放，方便對照 JSON。
