# 合成回覆（自我測試與校準用）

全部是自己寫的假回覆，不是任何模型的輸出。`judge.json` 是「預期的」盲評結果，只給 `selftest.py` 測試計分邏輯用；校準盲評模型時要把它換成模型實際的判定（見 `../calibration.md`）。

| 資料夾 | 內容 | 預期 |
|---|---|---|
| `good` | 繁體、台灣用語 | 三項都過 |
| `simplified` | 簡體、大陸用語 | 字體與用語不過 |
| `mainland_vocab` | 繁體字但 P4、P5 用大陸用語 | 字體過、用語不過 |
| `loop` | 只有 P1，同一句重複 6 次 | P1 連貫性不過 |
| `offtopic` | 只有 P2，內容答非所問（講咖啡） | 盲評應判 false |
