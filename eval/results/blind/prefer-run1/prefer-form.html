- **Each developer has their own key.** Every person makes an age keypair and you list all four public keys in `.sops.yaml`. Anyone on that list can decrypt with their own private key. Nobody shares a password.
- **Cutting someone off.** Remove their public key, re-encrypt with a new data key, and change the actual secrets. Step 7 explains why you have to change the secrets too.

**My assumptions:** you have Node.js 18 or newer, your spec is JSON or YAML (a local file or a URL), and your API uses header-based auth such as a bearer token or API key. I haven't run any of this on your machine. The flags below come from the project's current README.

## Install and first run

**1. Install.** Nothing to install globally. `npx -y` downloads and runs the package. If you want a fixed version for reproducibility, pin one, e.g. `@ivotoby/openapi-mcp-server@<version>`, and check npm for the latest.

    --openapi-spec ./openapi.yaml \
    --headers "Authorization:Bearer $INTERNAL_API_TOKEN"
```

- **Claude Code:**

  claude mcp add internal-api \

  {
    "mcpServers": {

        "command": "npx",
        "args": ["-y", "@ivotoby/openapi-mcp-server"],
        "env": {
          "API_BASE_URL": "https://internal-api.example.corp",
          "OPENAPI_SPEC_PATH": "/abs/path/openapi.yaml",
          "API_HEADERS": "Authorization:Bearer YOUR_TOKEN"
        }
      }
    }
  }
  ```

## Settings worth knowing
- **Limit what agents can do.** By default every operation becomes a tool. You can narrow that with `--tag`, `--exclude-tag`, `--tool`, `--resource <path-prefix>`, or `--operation get`. For example, `--operation get` makes the agents read-only until you trust the setup.
- **Big specs:** `--tools dynamic` gives agents a few tools for discovering and calling endpoints, instead of hundreds of separate tools that fill up their context.
- **Internal TLS:** `--ca-cert` adds your corporate CA, and `--client-cert`/`--client-key` handle mTLS. Use this rather than `--reject-unauthorized false`.
- **Keep tokens out of committed config.** Use environment variables or your client's secret handling. Also note that verbose logging is on by default.

我用 Markdown 寫中文技術文件，一個段落就是一整行。每次 git diff 都是整行紅綠，根本看不出改了哪幾個字。是不是要另外裝什麼 diff 工具？我在 Ubuntu 上，git 已經裝好了。

A

# 不用另外裝工具，git 內建的 word diff 就能做到

要加的只有一個設定。git 有 `--word-diff` 和 `--color-words`，只顯示行內改動的部分。

但直接用在中文上沒有效果。git 預設用空白切詞，一整段中文中間沒有空白，會被當成一個「詞」，結果還是整段紅綠。所以要給它一個正則，**把每個中文字當成一個單位，英文單字保持完整**。

## 主要推薦：用 `--color-words` 加上自訂切詞規則

### 1. 先試一次（不用改任何設定）

在你的 repo 裡執行：

```bash
git diff --color-words='[A-Za-z0-9_]+|[^[:space:]]'
```

- `[A-Za-z0-9_]+`：英文、數字、變數名稱整個當成一個詞，例如 `config_file`
- `[^[:space:]]`：其他非空白字元各自算一個單位，所以每個中文字和標點都分開比對

輸出會是同一行裡只有改到的字變紅或變綠。如果終端機沒有顏色，或你想複製貼上，可以改用文字標記：

```bash
git diff --word-diff=plain --word-diff-regex='[A-Za-z0-9_]+|[^[:space:]]'
```

刪掉的字顯示成 `[-舊字-]`，新增的字顯示成 `{+新字+}`。

### 2. 只對 Markdown 套用，設定一次就好

在 repo 根目錄的 `.gitattributes` 加一行（沒有這個檔就新建）：

```
*.md diff=cjk
```

然後設定這個 `cjk` diff driver 的切詞規則：

```bash
git config --global diff.cjk.wordRegex '[A-Za-z0-9_]+|[^[:space:]]'
```

之後只要打 `git diff --color-words` 或 `git diff --word-diff`，`.md` 檔就會自動用這個規則，其他程式碼檔案不受影響。

### 3. 設一個短指令（可選）

git 沒有「預設開啟 word diff」的設定，所以通常用 alias：

```bash
git config --global alias.wdiff 'diff --color-words'
```

以後打 `git wdiff` 就可以了。`git wdiff --cached` 和 `git wdiff HEAD~1` 這類寫法照常能用。`git log -p --color-words` 和 `git show --color-words` 也一樣有效。

### 我假設的前提

- **系統 locale 是 UTF-8**。Ubuntu 預設是 `en_US.UTF-8` 或 `C.UTF-8`，通常沒問題。如果中文字被切成亂碼（例如出現 `<E4>` 這種位元組），用 `locale` 檢查一下，確認 `LANG` 結尾是 `.UTF-8`。
- 我沒有在你的機器上實際跑過這些指令，請以你那邊的輸出為準。

## 補充：另一個習慣上的做法

很多人寫中文 Markdown 會改成**一句一行**，也就是在 `。`、`？` 後面換行。Markdown 渲染時同一段落裡的單一換行不會變成斷行，結果看起來一樣，但 diff 天然就是逐句的，`git blame` 和 merge 衝突也會清楚很多。這可以和上面的 word diff 一起用。

## 如果之後想要更好看的介面

- **delta**（`sudo apt install git-delta`）：有並排顯示、語法高亮。不過它預設的行內比對對中文是以整段連續中文為單位，效果不如上面的 `--color-words`，所以只是錦上添花，不能取代上面的設定。
- **diff-highlight**：Ubuntu 的 git 套件附帶，在 `/usr/share/doc/git/contrib/diff-highlight`，需要先 `make` 才能用。它只標出前後相同部分中間的差異區段，適合一段只改一處的情況。

結論：先跑第 1 步那行指令看效果，滿意的話再做第 2、3 步，什麼都不用裝。

My recommendation is to use **mdpo** to handle the Markdown structure and **liaad/Tradutor** to do the translation, run locally through **Ollama** with a small script connecting the two. I haven't run any of this on your machine. Below I mark what I checked and what I'm assuming.

## Why this setup

- **It targets European Portuguese specifically.** [Tradutor](https://huggingface.co/liaad/Tradutor) is an English→European Portuguese model from LIAAD (University of Porto). It was trained on a large European Portuguese parallel corpus and tested with a classifier that tells European from Brazilian Portuguese ([paper](https://arxiv.org/abs/2502.14385v1)). General-purpose models are trained mostly on Brazilian text, which is why yours keep producing it. Tradutor is an 8B model whose card shows GGUF, Ollama and llama.cpp options. At Q4 it needs about 5 GB of RAM, so it fits in 16 GB on CPU.
- **The model never sees your code blocks.** [mdpo](https://mondeja.github.io/mdpo/latest/rationale.html) splits each Markdown file into translatable strings and leaves fenced code blocks out by default. It then rebuilds the Markdown from the original file plus the translations, so the code blocks are copied over byte for byte.
- **URLs are hidden from the model.** Before sending each string, the script swaps inline code, link targets and bare URLs for placeholders like `⟦0⟧`, and puts them back afterwards. If any placeholder goes missing, it keeps the English and marks the string `fuzzy` for review rather than writing broken output.
- **Bonus:** you get one `.po` translation file per document. When a doc changes, a re-run only translates the new strings. Lisbon staff can also fix wording in [Poedit](https://poedit.net/) without touching the Markdown.

## The script: `translate_po.py`

```python
#!/usr/bin/env python3
"""Fill empty msgstr entries in a PO file using local Tradutor via Ollama."""
import json, re, sys, urllib.request
import polib

MODEL = "hf.co/liaad/Tradutor:Q4_K_M"
API = "http://localhost:11434/api/chat"
# inline code, link/image targets "(url)", autolinks, bare URLs
PROTECT = re.compile(r"`[^`\n]+`|\]\([^)\s]+(?:\s+\"[^\"]*\")?\)|<https?://[^>]+>|https?://[^\s)>\]]+")

def llm(text):
    body = json.dumps({
        "model": MODEL, "stream": False,
        "options": {"temperature": 0},
        "messages": [
            {"role": "system", "content": "You are a translator from English to European Portuguese"},
            {"role": "user", "content": "Translate this text from English to European Portuguese. "
             "Keep every ⟦n⟧ placeholder and all Markdown markup exactly as is. "
             f"Output only the translation: {text}"},
        ],
    }).encode()
    req = urllib.request.Request(API, body, {"Content-Type": "application/json"})
    with urllib.request.urlopen(req, timeout=600) as r:
        return json.load(r)["message"]["content"].strip()

def translate(text):
    saved = []
    def mask(m):
        s = m.group(0)
        if s.startswith("]("):              # keep "]" visible, hide "(url)"
            saved.append(s[1:]); return f"]⟦{len(saved)-1}⟧"
        saved.append(s); return f"⟦{len(saved)-1}⟧"
    out = llm(PROTECT.sub(mask, text))
    for i, s in enumerate(saved):
        if out.count(f"⟦{i}⟧") != 1:
            return None                        # placeholder lost -> don't trust it
        out = out.replace(f"⟦{i}⟧", s)
    return out

po = polib.pofile(sys.argv[1])
for e in po:
    if e.msgstr or e.obsolete:
        continue
    t = translate(e.msgid)
    if t is None:
        e.msgstr = e.msgid
        e.flags.append("fuzzy")
        print(f"[fuzzy] {sys.argv[1]}: {e.msgid[:60]!r}", file=sys.stderr)
    else:
        e.msgstr = t
    po.save()   # save after each entry so an interrupted run can resume
```

## The script: `md2ptpt.py` (Python standard library only)

```python
#!/usr/bin/env python3
"""Translate a folder of Markdown (en -> pt-PT) via a local llama-server.
Fenced code and front matter are copied verbatim; URLs, inline code and HTML are masked."""
import json, re, sys, pathlib, urllib.request

API = "http://127.0.0.1:8080/v1/chat/completions"
SYSTEM = (
    "You are a professional translator. Translate the user's Markdown from English into "
    "EUROPEAN Portuguese (Portugal, pt-PT, AO90 spelling). Never use Brazilian Portuguese. "
    "Use: ficheiro (not arquivo), ecrã (not tela), utilizador (not usuário), equipa (not equipe), "
    "registo (not registro), contacto (not contato), guardar (not salvar), transferir (not baixar), "
    "aplicação (not aplicativo), telemóvel (not celular), eliminar (not deletar); "
    "use 'estar a + infinitivo' (está a correr), never the gerund (está rodando); "
    "prefer clitic after the verb (configura-se). "
    "Keep every token like ⟦0⟧ exactly as is. Keep all Markdown syntax (#, -, *, |, [ ], links). "
    "Output ONLY the translation, with no comments or quotes."
)
FENCE = re.compile(r"^\s{0,3}(`{3,}|~{3,})")
PROTECT = re.compile(
    r"`+[^`\n]*?`+"                    # inline code
    r"|(?<=\])\([^)]*\)"                # link/image target (url "title")
    r"|^\s*\[[^\]]+\]:\s*\S+.*$"        # reference link definitions
    r"|https?://[^\s)\]>]+"             # bare URLs
    r"|<[^>\n]+>", re.M)                # autolinks and HTML tags
TOKEN = re.compile(r"⟦\d+⟧")
BR = re.compile(r"\b(arquivos?|usuári\w*|tela|equipe|registro|contato|salvar|baixar|aplicativo|"
                r"celular|deletar|est(?:á|ão|ava|avam)\s+\w+ndo)\b", re.I)

def ask(text):
    body = json.dumps({"messages": [{"role": "system", "content": SYSTEM},
                                    {"role": "user", "content": text}],
                       "temperature": 0, "max_tokens": 2048}).encode()
    req = urllib.request.Request(API, body, {"Content-Type": "application/json"})
    with urllib.request.urlopen(req, timeout=1800) as r:
        return json.load(r)["choices"][0]["message"]["content"].strip()

def translate_para(para, name):
    saved = []
    def keep(m):
        saved.append(m.group(0))
        return f"⟦{len(saved) - 1}⟧"
    masked = PROTECT.sub(keep, para)
    if not re.search(r"[A-Za-z]{2,}", TOKEN.sub("", masked)):
        return para                                 # nothing translatable
    want = sorted(TOKEN.findall(masked))
    for _ in range(2):                              # one retry
        out = ask(masked)
        if sorted(TOKEN.findall(out)) == want and out.count("|") == masked.count("|"):
            return TOKEN.sub(lambda m: saved[int(m.group(0)[1:-1])], out)
    print(f"  ! {name}: kept English (placeholders broke): {para[:60]!r}", file=sys.stderr)
    return para

def translate_file(src, dst):
    lines = src.read_text(encoding="utf-8").splitlines(keepends=True)
    out, para, fence, start = [], [], None, 0
    if lines and lines[0].strip() == "---":         # YAML front matter: verbatim
        end = next((j for j in range(1, len(lines)) if lines[j].strip() in ("---", "...")), None)
        if end:
            out, start = lines[:end + 1], end + 1
    def flush():
        if para:
            text = "".join(para); body = text.rstrip("\n")
            out.append(translate_para(body, src.name) + text[len(body):])
            para.clear()
    for line in lines[start:]:
        m = FENCE.match(line)
        if fence:
            out.append(line)
            s = line.strip()
            if s and set(s) == {fence[0]} and len(s) >= len(fence):
                fence = None
        elif m:
            flush(); fence = m.group(1); out.append(line)
        elif not line.strip():
            flush(); out.append(line)
        else:
            para.append(line)
    flush()
    result = "".join(out)
    dst.parent.mkdir(parents=True, exist_ok=True)
    dst.write_text(result, encoding="utf-8")
    # sanity checks
    url = re.compile(r"https?://[^\s)\]>\"']+")
    if sorted(url.findall(src.read_text(encoding="utf-8"))) != sorted(url.findall(result)):
        print(f"  ! {src.name}: URL mismatch, check manually", file=sys.stderr)
    for w in sorted({m.group(0).lower() for m in BR.finditer(result)}):
        print(f"  ? {src.name}: possible pt-BR: {w}", file=sys.stderr)

if __name__ == "__main__":
    src_root, dst_root = map(pathlib.Path, sys.argv[1:3])
    for f in sorted(src_root.rglob("*.md")):
        dst = dst_root / f.relative_to(src_root)
        if dst.exists():
            continue                                # resumable
        print(f"translating {f}")
        translate_file(f, dst)
```
